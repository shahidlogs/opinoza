Fix the withdrawal transfer email issue in Opinoza.

Issue:
When admin marks a withdrawal as paid/transferred, the system shows this message:

"⚠ Withdrawal marked as paid, but email could not be sent."

This means the withdrawal status is being updated successfully, but the confirmation email is failing.

Goal:
When a withdrawal is marked as paid/transferred, the user must receive an email confirming that the amount has been transferred.

Tasks:

1. Find the exact code path
- Search for this message:
  "Withdrawal marked as paid, but email could not be sent"
- Identify the API endpoint / admin action that marks withdrawal as paid
- Identify the email-sending function used after status update

2. Debug why email sending fails
Check:
- SMTP / email environment variables
- Nodemailer configuration
- Sender email credentials
- Missing recipient email
- Invalid user email lookup
- Email template errors
- Try/catch block hiding the real error
- Production logs around the failure

3. Improve error logging
- Log the real email error in backend logs
- Include withdrawal ID, user ID, and recipient email
- Do not expose sensitive SMTP credentials

4. Fix the email sending
- Ensure the email is sent after successful payment marking
- Email should include:
  - User name/email
  - Withdrawal amount
  - Transfer/payment confirmation
  - Date/time
  - A short professional message

5. Keep payment status safe
Important:
- Do not create duplicate transfers
- Do not change wallet balances incorrectly
- Do not reverse paid status unless explicitly needed
- If email fails, log it clearly so admin can retry or investigate

6. Add/verify a retry option if possible
- If email fails, admin should be able to resend the transfer confirmation email manually
- If not implemented now, at least structure the code so it can be added easily

7. Testing
- Mark a test withdrawal as paid
- Confirm status changes to paid/transferred
- Confirm user receives email
- Confirm admin no longer sees:
  "Withdrawal marked as paid, but email could not be sent."
- Confirm backend logs show no email error

Expected result:
When admin transfers/marks withdrawal as paid, Opinoza sends a successful email notification to the user confirming the amount transfer.
